# A Müntz Space-Time Spectral Method for the Time-Fractional Nonlinear Schrödinger System

This repository accompanies the research paper entitled *A Müntz space-time spectral method for the time-fractional nonlinear Schrödinger system* by Mahmoud Lotfi.

## Method

The code implements a space-time spectral approach using a Müntz-type temporal basis and Legendre spatial collocation. The method is designed for time-fractional nonlinear Schrödinger systems, including problems coupled with a Poisson equation.

## Numerical experiments

The repository is intended to provide the implementation and scripts associated with the numerical experiments reported in the paper, including comparisons with L1 time-stepping schemes and standard polynomial collocation.
